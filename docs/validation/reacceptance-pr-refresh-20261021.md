## 浏览器与发布约束

- 共用 Cloak 配置；真实进程含 headless 参数。显窗和无头切换保留 Cookie 与 localStorage。
- 窗口仍打开时自动保存；可信输入重置计时，脚本伪事件不重置；第二个 watcher 不会重复启动。
- 本地真实页面验证单站 Cookie、www 子域存储清理，另一站保持原样；169 项原有网站 Cookie 前后哈希一致。
- 十分钟自动关闭：使用真实 600 秒阈值；30 秒轮询在 630 秒确认浏览器与 watcher 均退出，用户原有 Bridge 保留。关闭后直接搜索会自动以无头 Cloak 重开，返回一条结果；收尾再次关闭浏览器和 watcher。
- 本地来源只读复用；来源站点 Cookie 哈希不变。导入范围仍是 Cookie，未承诺复制完整浏览器存储。
- OpenCLI 1.8.7 的 2,340 个发布文件与官方归档一致。没有修改上游源码、增加逐站 DOM 提取、恢复 ask 或 Reach MCP。
- wheel 含 49 个生产 Python 文件，逐一对应源码；无 API 原型、退休模块、维护者路径或密钥；小宇宙保留。
- setup 成功，安装后能力表和 Skill 已同步；Cursor/Codex 配置哈希未变化，依赖没有自动升级。
- Windows 真机、空环境冷安装仍待验。当前 `release_ready=false`，PR 和发版检查必须拒绝放行。
