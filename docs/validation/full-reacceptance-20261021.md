## 需要修复的程序问题

1. **GitHub 的公开降级仍会被登录阻断。** 在新的隔离 HOME 中，同一条真实 CLI 搜索默认返回 NEED_LOGIN；加上 `--backend github-api` 后返回公开仓库。没有退出或更改用户真实 GitHub 登录。`channels/github.py` 将 gh 未配置凭据归为 NEED_LOGIN，`runtime/dispatch.py` 遇此代码直接结束，公开 API 没被调用。
2. **execute 对公开原生动作仍准备浏览器。** 从浏览器关闭状态分别查询同一条雪球行情：直接命令不启动浏览器；execute 返回同样的腾讯行情，同时启动 Cloak。`runtime/flow.py:prepare` 依照整个渠道的 login_url 准备会话，没有区分此动作是否需要浏览器。
3. **错误分类没有统一到所有原生客户端。** 隔离复现中，雪球把普通 HTTP 403 和无效 JSON 都报为 NEED_LOGIN，GitHub 把普通 403 报为 RATE_LIMITED；真实 YouTube 请求的机器人验证也被报成 NEED_LOGIN。这些信号分别需要按权限、服务/格式错误和平台验证处理，不能直接引导重登。
4. **未登记缓存会被认领并删除。** 在隔离目录先创建未登记的 cache/用户文件，再调用 install_env：整个 cache 被记入台账，文件本身未登记；实际执行隔离 uninstall 后，文件消失。真实用户目录未被卸载或删除。
5. **真实验收门禁不完整。** PR CI 只跑自动化和打包；真实动作检查在 tag 发版阶段。检查器在一个隔离样本里，对 release_ready=false 和 Windows 待验字段返回无错误。目前仍因缺少 9 个真实动作而阻止发版；未来补齐动作后，这两项额外条件也必须被明确执行。

次级待收口：系统临时文件目录、英文 Skill 说明、Windows 真机与空环境冷安装、真实下载失败后的系统 Chrome 回退分支。
